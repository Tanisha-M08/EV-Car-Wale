# Design Patterns

Key patterns driving UI orchestration and calculation layers.

## Core Patterns
1. **Event Delegation**: Centralized navigation handling in `handleRouting` and re-binding click elements on local DOM updates.
2. **Dynamic UI Rendering**: Functional programming templates (`specsHtml`, `reviewsHtml`) combined with local database mapping functions.
3. **Linear Regression & Math Modeling**:
   - Range estimation: base range discounted by environmental variables (speed, AC, passengers, traffic).
   - Cost projection: base petrol mileage vs dynamic EV battery consumption values.
4. **State Persistence**: Using browser `localStorage` for wishlisted vehicles cache.
