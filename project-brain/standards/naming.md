# Naming Conventions

Structured rules for files, variables, and CSS class alignments.

## Guidelines
1. **JavaScript**: Use camelCase for variables, constants, functions, and event bindings (e.g. `animateSavingsNumber`, `activeVariantIdx`).
2. **HTML Elements**: Use snake-case or kebab-case for IDs and names (e.g. `chk-live-apartment`, `modal-info-reader`).
3. **CSS Classes**: Use standard Tailwind CSS groupings or clean modular suffixes.
