# Documentation Standards

Rules for code comments, design docs, and memory synchronization logs.

## Guidelines
1. **Comment Preservation**: Do not remove existing function docstrings or structural comments unless requested.
2. **Task Walks**: Update walkthrough docs with specific layouts, details, and verification tests.
3. **Memory Sync**: Record changes incrementally inside the `project-brain/memory/` and `project-brain/tasks/` logs.
