# Project Dependencies

The project maintains a zero-build setup, relying on CDN endpoints and standard browser libraries.

## External Libraries
1. **Tailwind CSS Play CDN** (`https://cdn.tailwindcss.com`): Utility-first styling compiler.
2. **jsPDF CDN** (`https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js`): Generates and downloads PDF documents.
3. **Google Fonts** (`https://fonts.googleapis.com`): Loads Plus Jakarta Sans and Inter font faces.
