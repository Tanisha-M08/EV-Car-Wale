# Project Overview: EVcarwale

EVcarwale is an interactive client-side Single Page Application (SPA) providing a comprehensive electric vehicle marketplace for Indian consumers.

## Main Value Propositions
1. **Interactive Showroom**: Explore popular, latest, and upcoming EVs in India.
2. **Real World Range Calculator**: Dynamic range estimator based on traffic, AC settings, weather conditions, driving style, and passenger load.
3. **Petrol Savings Calculator**: Shows monthly, annual, and 5-year savings compared to an equivalent ICE vehicle.
4. **EV Buying Guide**: Beginner-friendly guides with embedded custom SVG diagrams and technical definitions (e.g. LFP vs NMC, 800V Architecture, Regenerative braking).
5. **Apartment Charging Guide**: Built-in checklists, installation guidelines modal, and client-side RWA Request Letter PDF generator.
